# ФотоОпис

Веб-приложение для телефона: фотографируете станок, оборудование или инструмент (до 10 фото), Gemini заполняет шаблон описания, а готовый текст вместе с фото отправляется вам на почту.

## Как устроено

```
index.html          ← интерфейс: камера, шаблон, результат (сжимает фото до 1280px)
api/describe.js     ← фото + шаблон → Gemini → текст
api/send.js         ← текст + фото → письмо через Resend
api/_shared.js      ← пароль, проверка фото (не эндпоинт)
```

Ключи хранятся только в настройках Vercel, в коде и на телефоне их нет.

## Деплой на Vercel (≈15 минут)

1. **GitHub.** Создайте пустой репозиторий (например `foto-opis`) и загрузите туда эти файлы.
2. **Resend.** Зарегистрируйтесь на resend.com и создайте API key (раздел API Keys).
   Пока домен не подключён, Resend отправляет письма только на адрес, с которым вы зарегистрировались. Для MVP этого достаточно.
3. **Vercel.** Add New → Project → выберите репозиторий. Framework Preset: **Other**. Ничего больше не меняйте.
4. Перед нажатием Deploy откройте **Environment Variables** и добавьте:

| Имя | Значение |
|---|---|
| `GEMINI_API_KEY` | ключ из Google AI Studio |
| `RESEND_API_KEY` | ключ из Resend |
| `MAIL_TO` | ваш email (тот же, что в Resend); несколько адресов через запятую |
| `APP_PASSWORD` | любой пароль для входа в приложение |
| `GEMINI_MODEL` | *(необязательно)* модель, по умолчанию `gemini-2.5-flash` |

5. Нажмите **Deploy**. Через минуту получите ссылку вида `foto-opis.vercel.app`.
6. На телефоне откройте ссылку → «Поделиться» → **«На экран Домой»**.

Если переменные добавили после деплоя: Deployments → «⋯» → **Redeploy**, иначе функция их не увидит.

## Если что-то не работает

- **«Введите пароль приложения»**: пароль на телефоне не совпадает с `APP_PASSWORD`.
- **«Не задан GEMINI_API_KEY»**: переменная не добавлена или не было Redeploy.
- **«Почтовый сервис отказал»**: `MAIL_TO` не совпадает с email аккаунта Resend, или неверный ключ.
- **Ошибка про модель**: Google переименовал модель. Посмотрите актуальное имя в AI Studio и задайте его в `GEMINI_MODEL`.
- Подробности ошибок: Vercel → проект → **Logs**.

## Конфиденциальность

На бесплатном тарифе Gemini Google может использовать запросы для улучшения моделей. Если фото оборудования конфиденциальны, включите платный тариф в Google AI Studio.
